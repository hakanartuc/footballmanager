# Faz 1A — App: Tactics, Narration and Live Text Match Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The player edits the club's three tactic slots with the full 16.1 set, chooses on match day between "play quickly" and "watch", and watches the user match as a Turkish or English narration feed at 1×/2×/4× with pause, substitutions, mentality and tactic changes, half-time access and a post-match report — on top of the Faz 1a engine merged in `main` (engine 0.2.0, schema 3).

**Architecture:** The engine's `MatchSession` lives inside the engine isolate; the UI drives it through five new `EngineGateway` methods (`startMatch`, `matchRun`, `matchApply`, `finishMatch`, `matchReport`) that exchange small immutable views (`MatchStart`, `MatchBatch`, `StepView`, `MatchReport`) built by `SnapshotBuilder`. A `MatchController` (ChangeNotifier) owns the live match: it ticks the session at the chosen speed, auto-pauses on key events, applies the user's `MatchCommand`s and finishes the day; no autosave runs while it is open. Narration is a pure, locale-specific template engine in the app (`Narrator`) fed by `StepView`s; it draws from its own seeded rng and never from the engine. Tactics are edited through two new `EngineSession` mutations (`setTactic`, `selectTactic`) exposed on the gateway.

**Tech Stack:** Flutter 3.44 / Dart 3.12, `provider`, gen-l10n ARB, engine package `engine` 0.2.0 (path dependency). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-20-cm-simulation-design.md` — §5.4 (hızlı/detaylı mod, determinizm kuralı), §5.5 (dikey maç sunumu; 2D kısmı Faz 1b), §10 (Kadro → Taktik alt ekranı), §11 (Faz 1a satırı: anlatım TR+EN, metin tabanlı maç ekranı), §12 (ARB + Türkçe ek yardımcısı; isolate), §14-2/14-3 (kayıt gün sınırında; detaylı modda AI kararları otomatik uygulanır, kullanıcı müdahalesi sapmayı kabul eder; "hızlı bitir"), §14-9 (iki dilde ayrı havuzlar, ek uyumu), §16.1 (taktik tam seti; üç yuva; devre arası tam erişim), §16.8 (izleme modları "sadece sonuç" ve "sadece anlatım" 1–2 dk; hız 1×/2×/4×; önemli olaylarda otomatik duraklatma, ayarlanabilir; maç sonu: istatistik, puanlar, maçın adamı, sakatlık/ceza özeti), §18.1 (maç ayrıntısı saklanmaz; diğer kulüplerin özetleri 3 sezon). Engine plan hand-off notes: `docs/superpowers/plans/2026-10-23-faz1a-engine.md` Task 13; engine README "Interactive session API"; Faz 0B app plan `docs/superpowers/plans/2026-10-21-faz0b-app.md` (file structure, gateway pattern, test support).

## Global Constraints

- All Faz 0B constraints stay: engine only through `EngineGateway`; isolate in the real app, `InProcessGateway` in widget tests over the same `SnapshotBuilder`; every screen renders at 360×780 and 390×844 without overflow; all UI text from ARB; no `DateTime.now()` into game state; save slots and autosave policy unchanged (Spec §12, §16.12).
- **Save only at a day boundary**: no autosave, manual save or advance while a user match is open; the host guards with `EngineSession.userMatchInProgress` (engine throws `StateError` otherwise). App killed mid-match → next launch loads the morning autosave and the match starts again (Spec §14-2).
- **Watched == quick** by default: with the assistant on (`userManaged: false`) and no user command, `startMatch` + `matchRun` to the end + `finishMatch` leaves the world byte-identical to `playToday` with the same commands (engine contract; pinned in Task 2). User commands make the result diverge; that is accepted (Spec §14-3).
- **Narration consumes no engine randomness**: `Narrator` draws only from `SeededRng(fixtureId).fork('narration')`; the engine's rng is never passed to the app (Spec §5.4).
- Narration pools are written separately in Turkish and English (no translation), 8–15 variants per slot where the spec asks for them; Turkish templates use the suffix helper for case endings on names (Spec §5.5, §14-9).
- Timing targets at 1×: narration-only match 60–120 s wall clock for a normal match (Spec §16.8); 2× and 4× scale the step delay; "⏭ bitir" finishes the rest instantly.
- Engine stays deterministic and symmetric: the two tactic mutations are available for any club id; `startOfDay`/`playMatches` never consult `isUser`.
- Engine save schema stays **3** (no new persisted fields; pruning only removes data). Engine version 0.2.1 after Task 1.
- Commit per task; conventional commits; attribution trailer of the model that wrote the commit. Model per task tagged `[Model: Fable]` / `[Model: Opus]` per Spec §11.1; Fable reviews every Opus task directly (controller), separate Fable review for Tasks 1, 2 and 4 and for the whole branch at the end.
- Branch `faz1a-app` from `main`; push after every task; merge to `main` only after green tests and Hakan's approval.

## Review Focus

1. **App killed while a match is open** — on relaunch the newest autosave is the morning of the match day and "Maça çık" is offered again; the match restarts from kick-off with the same lineup; no half-day state is ever saved. Pinned in Task 4 (no autosave while `inMatch`) and Task 8 (integration restart).
2. **Invalid substitution from the UI** (player not on bench, no substitutions left, bringing on a player sent off, same player twice) — the sheet shows the engine's `CommandError` kind as a readable message and the match state is unchanged; the feed continues. Pinned in Task 4 (controller maps `CommandError` kinds) and Task 6 (sheet shows the text).
3. **Custom formation that is not a formation** (two goalkeepers, ten players, no goalkeeper in slot 0, a taker who is not in the squad) — the tactics screen refuses to save with the specific error; the engine refuses it too. Pinned in Task 1 (`validateTactic`) and Task 5 (screen).
4. **Locale switched while a match is open or on the report** — every narration line already in the feed re-renders in the new language (lines are regenerated from stored `StepView`s, never cached as text) and the report's labels follow. Pinned in Task 6.
5. **Extra time, shootout and abandonment** — a cup-style fixture (`MatchRules` with extra time and penalties; Faz 2 adds the cup, the engine already supports it) and a match abandoned after sendings-off narrate and finish without a crash: `ExtraTimeStart`, `ShootoutStart`, `ShootoutKick` and `FullTime(half: 5)` have lines, the score bar shows ET/pens, and the report shows the shootout. Pinned in Task 3 (pools) and Task 6 (screen with a scripted gateway).

**Interfaces:**

- Produces: `enum MatchSpeed { x1, x2, x4 }` with `Duration stepDelay` 600 / 300 / 150 ms; `enum MatchPhase { starting, playing, paused, halfTime, finished, failed }`; `final class FeedEntry { StepView step; }` (lines are regenerated from steps by the screen — Review Focus 4).
